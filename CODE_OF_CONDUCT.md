# Code of Conduct

## Our Pledge

We as members, contributors, and leaders pledge to make participation in our community a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our Standards

### Expected Behavior

- **Respectful Communication**: Use welcoming and inclusive language
- **Constructive Feedback**: Provide helpful, constructive criticism
- **Ethical Use**: Only use this tool for authorized security testing
- **Responsible Disclosure**: Report security issues responsibly
- **Professional Conduct**: Maintain professional standards in all interactions

### Unacceptable Behavior

- **Unauthorized Testing**: Using this tool without proper authorization
- **Harassment**: Any form of harassment, discrimination, or offensive comments
- **Malicious Use**: Using the tool for unauthorized access or malicious purposes
- **Disruptive Behavior**: Trolling, insulting/derogatory comments, or personal attacks
- **Inappropriate Content**: Publishing others' private information without permission

## Security Research Ethics

Given the nature of this project:

- **Authorization Required**: Always obtain proper authorization before testing
- **Responsible Disclosure**: Report vulnerabilities responsibly
- **No Malicious Use**: Do not use this tool for unauthorized access
- **Respect Privacy**: Do not expose sensitive information in issues or PRs
- **Legal Compliance**: Ensure all activities comply with applicable laws

## Enforcement

Instances of abusive, harassing, or otherwise unacceptable behavior may be reported to the project maintainers. All complaints will be reviewed and investigated promptly and fairly.

Project maintainers have the right and responsibility to remove, edit, or reject comments, commits, code, wiki edits, issues, and other contributions that are not aligned with this Code of Conduct, or to ban temporarily or permanently any contributor for other behaviors that they deem inappropriate, threatening, offensive, or harmful.

## Scope

This Code of Conduct applies within all project spaces, and also applies when an individual is officially representing the project in public spaces. Examples of representing a project include using an official project e-mail address, posting via an official social media account, or acting as an appointed representative at an online or offline event.
